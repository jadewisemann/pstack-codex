# pstack for Codex

원본 [pstack](https://github.com/cursor/plugins/tree/9f451cf875ad1239912762f67741e8e5ba6ac0f1/pstack)의 핵심 엔지니어링 흐름과 24개 원칙을 Codex 기본 도구로 실행하는 스킬입니다. 원본의 공식 배포판은 아닙니다.

작업에 맞게 조사 → 데이터 모양과 사용 예 → 설계 대안 비교 → 작업 분해 → 구현 위임 → 실제 동작 검증 순서로 진행합니다. 작업을 지휘하는 에이전트가 설계 선택과 최종 검증을 맡습니다. 단순 편집이나 일반 설명에는 전체 절차를 적용하지 않습니다.

## 설치

적용할 프로젝트 폴더에서 실행합니다. 대상 폴더가 이미 있으면 새로 복제하기 전에 기존 설치 상태를 확인하세요.

```sh
mkdir -p .agents/skills
git clone https://github.com/jadewisemann/pstack-codex.git .agents/skills/pstack-codex
```

Codex는 `.agents/skills`에서 로컬 스킬을 읽습니다. 새 스킬이 목록에 나타나지 않으면 Codex를 재시작하세요. 설치 위치와 탐색 방식은 [공식 Skills 문서](https://learn.chatgpt.com/docs/build-skills)를 따릅니다.

## 사용

```text
$pstack-codex 이 버그를 재현하고 원인을 고친 뒤 실제 동작까지 검증해줘.
```

기본 자동 선택도 허용합니다. 기능 개발, 버그 수정, 리팩터링, 성능 개선과 근거가 필요한 코드 조사에 사용합니다. 조사 요청은 조사 범위에서 끝내고, 리뷰 요청만으로 코드를 수정하지 않습니다.

## Codex에 맞춘 실행

- 현재 제공되는 하위 에이전트 도구를 사용하고, 모델과 추론 수준은 현재 채팅의 설정을 물려받습니다.
- 구조가 다른 설계안을 비교하고 구현 결과를 별도로 검증합니다. 같은 모델의 별도 실행을 서로 다른 모델의 합의로 표현하지 않습니다.
- 병렬 작업은 쓰기 위치를 나눕니다. 작업 폴더와 Git index를 공유하면 쓰는 담당자를 한 명으로 정합니다.
- 실제 사용자 경로를 확인합니다. 타입 검사나 구현자의 완료 보고만으로 동작이 검증됐다고 주장하지 않습니다.
- 사용자가 허용한 범위와 적용되는 `AGENTS.md`를 따릅니다. PR·외부 메시지·배포·병합 권한을 새로 부여하지 않습니다.

## 구성과 검증 범위

[SKILL.md](SKILL.md)가 진입점입니다. 작업별 절차는 [workflows.md](references/workflows.md), 원칙별 적용 조건은 [principles.md](references/principles.md), 원본과의 대응 및 변경점은 [upstream.md](references/upstream.md)에 있습니다.

2026-10-07에 스킬 형식, 상대 참조, 원본 24개 원칙의 식별자 대응을 확인했습니다. 별도 로컬 프로젝트에서 라벨 순서 버그 수정, 읽기 전용 영수증 조사, 배송 상태 변경의 세 사례를 실행하고 결과를 다시 확인했습니다. 이는 사례 확인이며 모든 작업에서 같은 판단이나 품질을 보장하지 않습니다.

이 패키지는 지침형 스킬입니다. 별도 실행기나 추가 런타임 의존성이 없으며, 규칙 준수를 강제하는 프로그램·보안 격리 장치·스케줄러·자동 병합기는 제공하지 않습니다. 원본 51개 스킬과 23개 플레이북 전체의 호환 구현도 아닙니다.
